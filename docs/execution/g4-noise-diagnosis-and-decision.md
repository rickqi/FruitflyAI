## 2. 噪声主因判定：测量噪声 vs 上下文方差

### 2.1 结论（含比例与其严格边界）

> **在门的工作点上，Var(Δ) 的主体是"比一窗更快"的涨落；其中「指标测量/端点采样噪声」与「亚窗尺度的真实行为变化」在现有数据上不可分辨。可分层（分类/电平类）上下文对 Δ 无可检验的解释力（键恒定/分层无功效）；补充实测：把单差换成 A-B-A 配对（k=1）只把 SD 从 0.0907 降到 0.0892（−1.7%）⇒ 在单窗尺度上可由"配对/差分"消掉的成分≈0。但电平序列存在分钟级连续漂移，它使"加长窗口"的收益在 k≈4 窗后反转。**

这一表述是 t1 的定性方向 + t3 的三处修正 + 我本次两项新实测的合成，**不含**"测量噪声占 X%、上下文方差占 Y%"的单点比例——该比例在现有数据上不可得（§2.5）。

### 2.3 必须标注的两条"旧断言不可用"

1. **【已证伪】t1-E4"≥89.5% 的 Var(Δ) 不可能由窗口级上下文解释，95% 上界 10.5%"**：反解方向错误。由 `r₁ = s·ρ_C − (1−s)/2` 解 `s = (r₁+0.5)/(ρ_C+0.5)`，`s` 随 `ρ_C` 减小而**增大**；同一 r₁ 上侧端点下的正确 95% 上界 = **31.5%**（= 1+2·(−0.3427)），点估计 ≈0。t3 的 MC 与物理口径仿真均证实（ρ_c=0.99、上下文占电平方差 99% 时 r₁ 仍只 −0.244）。⇒ 只能说"**≤31.5%（95% 上界，附平稳/一阶结构假设）**"，不能说"≥89.5% 非上下文"。
2. **【已证伪】t1-§0"主因 = 测量噪声"**：r₁ = −0.5044 与"亚秒级真实行为变化（146/146 `oscillating`）"同样吻合；相邻窗 Δ 对慢变上下文天然免疫（物理口径仿真）。可支持的只有"**非窗口级上下文**"。
3. 另（t2/t3）：**t2-(iii)"即使逐字实施 §5 也过不了"的论证方法不成立**（它把估计器固定为端点差，而 §5 明文要求"长窗均值"），但其**方向**已由 t3 用实测补成硬证据（§3.3）。

### 2.4 我本次新增的实测：分钟级漂移确实存在，并封住"加长窗口"的收益

**方法**（`.tmp/g4_diag/t4_pooling_projection.py`、`t4_level_structure.py`，全部只读）：从日志逐窗记录恢复 **147 个连续 A/A 窗的 delta**（与冻结快照 `delta_stats` **逐位相符，EXACT MATCH**；口径：仅每窗一个端点采样，掩掉窗内 ~12 点），再由 `xᵢ = xᵢ₋₁ + δᵢ` 精确重建**电平序列**（相邻窗以"上一窗收点"为锚，连加即恒等），然后在同一序列上算两类"改带宽"统计量的 null 分布（A/A 无处理 ⇒ 任何偏离都是噪声）。

| 量 | 实测值 | 含义 |
|---|---|---|
| 每窗漂移 `μ` | **+0.007633 fitness/窗**（147 窗合计 **+1.122**）【实测-t4】 | 电平在 ~2.6 h 内单向上行；**线性漂移在 A-B-A 差分中精确抵消** |
| 电平序列 `Var(x)` vs 白噪模型 `Var(δ)/2` | **0.1082 vs 0.00411（26.3×）**；去线性趋势后 `SD=0.105`、游走范围 **−0.197…+0.288** | 电平的绝大部分方差来自"窗际趋势"，不是采样噪声 |
| 块均值标度（去趋势不成立，见下） | L 块均值 SD 相对白噪 `σ/√L` 的**膨胀**：L=1 **5.1×** → L=8 **13.8×** → L=32 **24.2×** | **【限制】**L=1 的膨胀主要来自线性斜坡；去趋势后仅 **2.7×**（`Var=0.0110`），且该估计的有效独立样本极少 ⇒ 只能定性说"存在慢分量" |
| **多窗池化（未配对）** `D_k = mean(后 k 窗) − mean(前 k 窗)`，去趋势 | empirical P95 最小值 **0.0956（k=3）**，bootstrap 置信上界最小 **0.102（k=4）**；k≥5 后**回升**（k=20 达 0.194） | 池化把"快噪声"压下去了（0.168→0.096，−43%），却把"分钟级漂移"放大（`E[D_k] = k·μ`）⇒ **k=4 是拐点** |
| 原始（未去趋势）池化 | 最小值 0.1264（k=4）/ 置信上界 0.1326（k=4） | 与 t2 的"≈37 窗池化可得 0.03（1/√k 假设）"**不符** |
| 需要的池化（若按 1/√k 假设） | 34.2 窗/臂【估算】 | 实测曲线在 k≤35 内**从未**接近 0.03 ⇒ **1/√k 假设被实测否定** |

> **【限制】必须随数字引用**：滑动窗位置高度重叠（k=20 时 108 个位置共享绝大部分数据），尾部估计（P95）本身不稳；`Var(x)` 这类"电平方差"估计在强自相关下有效独立样本极少。**稳健的是方向**（池化在 k≥4 后不再改善、任何 k≤35 都远高于 0.03——非重叠块交叉检验独立给出同向结果，见 §4.2），**不是曲线上的精确最小值**。

### 2.5 待验假设（本节不能裁的部分）

- **A1（待验，t1 提出、t3 与我一致）**：占主体的快涨落究竟是「指标测量/端点采样噪声」还是「亚窗真实行为变化」——**不可分辨**，因为主导项 `unstuck`（A/A p95 = 0.13755，占总噪声方差 ~78~88%）的输入 `net_disp_60s` **未落盘**。两者修法在统计上相同（窗内聚合 + 稳健分母 + 去饱和），但**物理含义与"可修"叙述不同**，不得混写。
- **A2（待验 ⇒ 已修正引用）**：`noise_p95` 在 n=147/172 时**未收敛**。t1 引用的"MC std 0.001（占门 5%）"是 bootstrap 自身重采样噪声；P95 估计量的非参 95% CI = **[0.1237, 0.2644]**（宽 80%，t3）【实测】。⇒ 引用噪声基底必须带 n 与 CI，且**不得**用 0.001 描述不确定性。
- **A3（本节裁定）**：H13 的**形式**裁定仍缺一项证据（逐窗 raw，§6）；但**实质**结论已由"CI 下界 4.1× 门限 + 两种改带宽路径实测均 ≥1.9× 门限"支撑（§4）。

## 4. 三条候选路径及取舍

**完整证据链（7 条，全部可复核）**：

1. **门的判据量远大于门限（多口径一致）**【实测-t4/t3】：n=147 时 `P95(δ)=0.1754`、**`P95|δ|=0.2495`**（规格 V9 名 `aa_p95_abs_delta`）、bootstrap 均值 0.1832、**规格要求的置信上界 0.2611**、非参 95% CI **[0.1237, 0.2644]** ⇒ **即使取 CI 下界也是 0.03 的 4.1×**；n≥100 的 812 条 gate 行 `noise_p95 ∈ [0.169207, 0.208242]`（5.64×~6.94×）。
