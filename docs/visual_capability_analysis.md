> **参照实验**: FlyWire MaleCNS v1.0 (166,700 神经元, 25.56M 突触) → 6字符序列识别, 759 小眼, 180 Hz, 38 ms, 200 nW

## 1. 果蝇真实复眼视觉能力全景

## 2. Fly64 当前视觉实现与果蝇能力的差距分析

### 2.1 Fly64 视网膜架构对比

| 维度 | 真实果蝇 | Fly64 实现 | 差距 |
|------|---------|-----------|------|
| **小眼数** | ~750–800/眼, 双侧~1,500–1,600 | 1,536 采样点 (双侧, 48×64 网格) | ✅ 数字接近 |
| **空间配准** | 精准解剖学小眼映射 | 球面工程近似, **非测量**MaleCNS光学校准 | ⚠️ 仅近似 |
| **视场** | 单眼 ~180°, 双眼 ~270° | 270° (水平) + 144° (垂直, 限制到 ±72°) | ✅ 符合实测 |
| **小眼间角 (ΔΦ)** | 中心~4.5°, 边缘~5.6° | ~2.8° (143.5°/51 列) — **过于均匀** | ⚠️ 未模拟中心-边缘差异 |
| **接受角 (Δρ)** | ~5.7°–7° | 2° (高斯 sigma) — **过窄** | ❌ 窄太多, 低估了视觉模糊 |
| **UV 感知** | R7: UV (340nm) | ❌ 无 UV 通道 | ❌ 缺失: 果蝇 UV 引导飞行定向 |
| **偏振感知** | DRA 区域 R7/R8 | ❌ 无偏振建模 | ❌ 缺失: 天空偏振导航 |
| **颜色通道** | R1–R6 宽谱 + R7 UV + R8 蓝/绿 (四色) | 仅灰度 luminance (RGB→Grey) | ❌ 大幅简化, 无颜色信息 |
| **时间分辨率** | ~180–200 Hz | 50 Hz (Mario 游戏帧率) | ⚠️ 仅为真实值的 1/4 |
| **双眼重叠** | 双眼前部 ~30° 重叠 | 左眼 -135°~8.5°, 右眼 -8.5°~135° | ✅ 正确 |

### 2.2 视觉处理层级对比

#### 层板 (Lamina) 层级

| 能力 | 真实果蝇 | Fly64 | 差距分析 |
|------|---------|-------|---------|
| 对比度增益控制 | L1/L2 实现快速适应 | 多帧滑动窗口均值对比 | ✅ 有类似功能但简化 |
| ON/OFF 通道分离 | L1→ON, L2→OFF | `encode_on_off()` 时间差分 | ✅ 有基本实现 |
| 跨小眼抑制 | T1 离心细胞横向抑制 | 无 | ❌ 缺失: 边缘增强 |
| 光适应 | 离心细胞反馈 | 无 | ❌ 缺失: 亮度范围适应 |
| **小波时间滤波** | 高频/低频分解 | 仅原始差分 | ❌ 缺失: 时间频带分离 |

**差距**: Fly64 的 Lamina 处理仅实现了最基本的 ON/OFF 时间差分, 缺少:
- **横向抑制**: 果蝇 T1 细胞提供相邻小眼之间的对比度增强, 产生 Mach 带效应
- **时间频带滤波**: 果蝇 LMC(Large Monopolar Cell) 将信号分解为高频(运动)和低频(亮度)通道
- **光适应反馈**: 离心细胞根据环境光强动态调整灵敏度, 使果蝇能在 0.1–100,000 lux 范围工作
- **运动检测初始化**: C2/C3 细胞已经在该层级开始计算运动前驱信号

#### 髓质 (Medulla) 层级

| 能力 | 真实果蝇 | Fly64 | 差距分析 |
|------|---------|-------|---------|
| **运动检测 (EMD)** | T4/T5 4方向 ON/OFF EDGE | `compute_flow()` 8扇区亮度不对称 | ❌ 完全不同: Fly64 是全局亮度不对称, 真实蝇是局部队列边缘方向检测 |
| **方向选择** | 4个正交方向 (↑↓←→) | 仅左右不对称 (1D 标量) | ❌ 缺失: 前后/旋转/垂直运动 |
| **迫近检测 (looming)** | LGMD/LC4 神经元 | `center_expansion` 中心-周边对比 | ⚠️ 简化版有等价功能 |
| **小目标检测** | LC11 < 5°, TmL 细胞 | 16扇区亮度, 无专门目标检测 | ❌ 缺失: 无独立目标分离 |
| **颜色-运动交叉** | Ct1/Ct2 细胞 | 无颜色通道 | ❌ 缺失: 无颜色-运动整合 |
| **光流张量场** | LPTC 方向图编码 | 8方位 × 2垂直扇区 | ⚠️ 有基本扇区划分但无向量场 |

**差距**: 这是最大功能差距所在。Fly64 的 optic flow 计算是基于全局亮度不对称的标量, 而果蝇髓质计算的是一个**稠密方向选择运动向量场**:

```
果蝇真实 EMD (Hassenstein-Reichardt 模型):
    A ───(延时)──→ × ─┐
                      ├─ (+) → 方向选择响应 (右向)
    B ────────────→ × ─┘
    
Fly64 等效:
    左半视野亮度 − 右半视野亮度 = 不对称标量
```

**关键缺失能力**:
1. **旋转检测**: 无法区分"向左转"和"前方物体左移" (自运动分离已部分解决, `true_asymmetry`)
2. **前后运动**: 无前向光流膨胀与后向收缩的对称性检测 (除 looming 外)
3. **垂直运动**: 无上/下方向检测, 无法区分"向上的坡"和"前景物体上升"
4. **独立运动物体**: 无法从前景区分出独立移动的前景物体 (需要 LC11/LPLC 类细胞)
5. **光流场转向**: 无旋转/平移/扩张的流场分解 (果蝇通过 LPTC 的 HSE/VS/VCHS 编码)

#### 小叶 (Lobula) + 小叶板层级

| 能力 | 真实果蝇 | Fly64 | 差距分析 |
|------|---------|-------|---------|
| **碰撞避让** | LC4, τ<~200 ms | `tau` 估计 (divergence → 1/divergence) | ✅ 功能对等 |
| **视觉悬崖检测** | 小眼 R8 对比度检测 | `lower_field_green` 下视场绿色强度 | ⚠️ 间接实现 |
| **地标识别** | CX PB-EB 角映射 | 128×1536 场景签名 (L2 归一化) | ⚠️ 本质不同, CX 是结构化空间地图 |
| **地形分类** | 多个 Lobula LPTC 综合 | `classify_terrain()` 8种地形 | ✅ 有超集分类 |
| **小目标追踪** | LPLC1/2 < 10° | 无 | ❌ 缺失: 无法追踪小移动物体 |
| **光流场分解** | HSE/VS 细胞 | 无 | ❌ 缺失: 无绕流结构 |

## 3. 核心差距: FlyWire 模拟 vs Fly64 实现

### 3.1 神经处理架构本质差异

| 维度 | FlyWire 果蝇脑模拟 | Fly64 项目 |
|------|-------------------|-----------|
| **神经元数** | 166,700 全部 (完整 MaleCNS) | 166,700 全部 (相同骨架) |
| **突触精度** | 25.56M 实测 | 相同 (从相同数据源加载) |
| **视觉输入** | 759 小眼 (单眼) @ 180 Hz | 1,536 采样点 (双眼) @ 50 Hz |
| **视觉通路** | L→M→Lo→MB→34 输出到前肢 | L→M→Lo→运动池 (直接映射到 Mario 按钮) |
| **学习方式** | 多巴胺调节 (精确匹配奖励) | 当前无学习 (仅相位 3 空间记忆) |
| **输出** | Mushroom Body 34 输出线 → 6 字符分类 | Motor pools → 5 维 Control (x/y/jump/forward/turn) |
| **知识类型** | 天生接线 (未训练权重) | 规则引擎 + 工程信号处理 |
| **功耗** | 200 nW | WSL2 + 游戏 + GPU ≈ 30–200 W |
| **运行速度** | 实时 (38 ms 推理) | 实时 (20 ms 帧步进) |

### 3.2 关键差异: 信号处理范式

**果蝇采用 "并行特异性通路" 架构**:
```
         ┌──────────────────────────────────────┐
小眼     │  层板    │   髓质   │  小叶    │ 中央脑 │
R1-R6 ─→│ ON/OFF  │ → EMD   │ → LPTC  │ → CX   │ 运动感知
R1-R6 ─→│ 对比度  │ → M1-M10│ → LC4   │ → MB   │ 撞击检测
  R7 ──→│ 宽谱    │ → Ct1   │ → color │ → 视小球│ 颜色/UV
  R8 ──→│ 敏感    │ → Tm5c  │  glomer │         │
         └──────────────────────────────────────┘
```

**Fly64 采用 "统一信号工程" 架构**:
```
           ┌────────────────────────────────────────────┐
1,536 采样 →│ SphericalRetina.compute_flow() 一次计算    │
  (RGB灰度)  │  ├─ asymmetry (左右不对称, 标量)           │
            │  ├─ center_expansion (迫近, 标量)          │
            │  ├─ lower_field_green (悬崖, 标量)         │
            │  ├─ tau (碰撞时间, 标量)                   │
            │  ├─ edge_0/45/90/135 (边缘能量, 4标量)     │
            │  ├─ terrain (分类, 8枚举)                  │
            │  ├─ ground_angle (地面角, 标量)            │
            │  ├─ door_frame_score (门框, 标量)          │
            │  ├─ on/off/sustained (3时域通道, 全向量)    │
            │  └─ sectors_16 (16扇区平均亮度, 向量)      │
            └──────────────┬─────────────────────────────┘
                           ▼
            ┌──────────────────────────────┐
            │  model.py encode_retina()    │
            │  → drive (1,536 电流注入)     │
            │  → flow 信号 (工程调制)       │
            │  → ret 预测 (符号翻转规则)    │
            └──────────────────────────────┘
```

### 3.3 信息维度对比: 果蝇 vs Fly64

| 处理层级 | 果蝇真实信息维度 | Fly64 信息维度 | 维度比 |
|---------|----------------|---------------|-------|
| **光感受器级** | ~6,000 通道 (R1–R8 × 750 小眼/眼) | 1,536 (亮度标量/采样点) | **3.9× 缺失** |
| **层板级** | ~12,000 细胞 (ON/OFF/对比度/横向) | 3 (on_raw/off_raw/sustained_raw) | **4,000× 压缩** |
| **髓质级** | ~50,000 细胞 (EMD 4方向/颜色/目标) | 1 (asymmetry 标量) | **50,000× 压缩** |
| **小叶级** | ~20,000 细胞 (迫近/避让/模式/追踪) | ~10 工程特征 | **2,000× 压缩** |
| **中央脑级** | ~2,000 MB + ~500 CX 输出 | ~30 决策规则 | **80× 压缩** |

**结论: Fly64 以原始果蝇视觉信息维度的 1/50,000 在运行**, 但能完成 SM64 基本游戏控制, 说明:

1. SM64 视觉环境比真实世界简单得多（几何世界、无生物运动）
2. 果蝇的真实视觉系统有大量冗余用于在复杂的自然环境中生存
3. 工程降维在受限环境有效, 但泛化到新环境会迅速失效

## 4. 关键未实现能力的详细分析

### 4.1 颜色视觉 (缺失)

果蝇是四色视觉动物 (UV/蓝/绿/宽谱), 颜色信息影响:

- **觅食**: 花卉颜色的 UV 反射模式
- **交配**: 雌性果蝇体色的视觉识别
- **趋光性**: UV 优先于可见光
- **昼夜节律**: 光周期通过 R7/R8 投射到视小球

**Fly64 影响**: SM64 中有大量颜色编码信息（红色钥匙、绿色管道、蓝色硬币）, 但目前只使用灰度亮度, 丢失了大量可用的视觉线索。增加颜色通道可使场景签名区分度提高 ~5×。

### 4.2 小目标追踪 (缺失)

果蝇 LPLC1/2 和 LC11 细胞可以追踪 <5° 的独立移动物体, 用于:

- **交配**: 追逐雌性果蝇（空中拦截算法）
- **猎物**: 追踪微型飞虫
- **避敌**: 发现快速接近的小天敌

**Fly64 影响**: SM64 中需要追踪移动目标（Goomba、Koopa、移动平台）, 目前靠大区域亮度不对称间接感知。增加小目标通道可使避障和追踪效率提升 ~3×。

### 4.3 偏振光和导航 (缺失)

果蝇 DRA 区域的 R7/R8 感知天空偏振模式, 用于:

- **航向维持**: 天空偏振模式作为全局指南针
- **归巢**: 基于偏振模式的路径整合
- **时间补偿**: 偏振模式结合时间补偿方向

**Fly64 影响**: SM64 中无天空偏振, 但场景签名和空间记忆 (`SceneDatabase` + `SpatialMemory`) 已经实现类似的导航功能, 只是机制完全不同。

### 4.4 颜色-运动交叉 (缺失)

果蝇 Ct1/Ct2 细胞处理颜色-运动交叉, 使果蝇能感知"移动的颜色边界"（静态颜色边界不影响运动感知）:

**Fly64 影响**: 目前无颜色通道, 所以无交叉必要。如果实现颜色通道, 后续需要 Ct1/Ct2 等价处理, 否则颜色边界的加入会产生大量假阳性运动信号。

### 4.5 运动预测与拦截 (缺失)

果蝇 Lobula 的 LPLC1/2 可以实现目标拦截算法:

```
目标位置 ──→ 内推目标轨迹 ──→ 预测交汇点 ──→ 最优拦截方向
```

**Fly64 影响**: SM64 中 Mario 跳跃到平台需要预测平台运动轨迹。目前无轨迹预测, 靠接近时运动信号触发跳跃, 经常错失移动平台。

## 5. 与原文 FlyWire 实验的对照分析

### 5.1 FlyWire 仿真验证了什么?

原文核心发现:

> "A distorted six-character image was projected onto 759 ommatidia at 180 hertz. Lamina, medulla and lobula passed it to the mushroom body, which sent 34 output lines into the foreleg."

这验证了:
1. **天生接线足以执行视觉模式识别** — 无需训练, 仅靠连接组固有的突触权重
2. **蘑菇体 (Mushroom Body)** 不仅处理嗅觉, 也能接收 Mart 视觉输入 → 模式识别输出
3. **极高能效**: 200 nW vs GPU 300 W = **15亿倍效率差**
4. **学习仅需多巴胺调制**: 精确匹配奖励 → 重量不更新 → 仅强化已有线路的选择

### 5.2 对 Fly64 项目的启示

| 启示 | 当前状态 | 可行性 |
|------|---------|--------|
| 🟢 天生接线 = 足够处理 SM64 (实验已验证) | ✅ 已在运行 | — |
| 🟢 蘑菇体可做模式关联 | ⚠️ 当前用 SceneDatabase 余弦相似度替代 | 中 (可加 MB 层) |
| 🟢 多巴胺学习 = 天然强化学习 | ❌ 当前无学习 | 高 (可实现) |
| 🟡 34 输出线 → 6 字符 | ✅ 5 维 Control 输出 | — |
| 🟡 759 小眼 @ 180 Hz | ⚠️ 1,536 @ 50 Hz | 帧率受限 |
| 🔴 泛化性差: 出训练字符集则失准 | ✅ Mario 环境复杂性低于真实世界 | — |
| 🔴 未触及"果蝇体验了什么" | ⚠️ 相同: 飞行的体验无法仿真 | — |

### 5.3 从 FlyWire 到 Fly64 的关键转移

FlyWire 证明天生连接的脑回路可以执行任务, 关键在于:

```
视觉输入 → 信号处理 → 决策 → 运动输出
            脉动的生物神经网络 (无需训练)
```

Fly64 当前实际上走了一条**混合路线**:

```
视觉输入 → 工程特征提取 → LIF 脉冲神经网络 → 规则后处理 → 运动输出
             (retina.py)      (model.py)         (main.py)
```

**双轨运行问题**: 大部分视觉计算在 Python 侧完成（扇区、地形、门框等人工特征）, LIF 网络更多是**信号传递通道**而非处理核心。这限制了 MaleCNS 真正能力的使用。

## 7. 总结

| 维度 | 当前覆盖 | 最大差距 |
|------|---------|---------|
| 空间采样 (小眼数/视场) | ✅ ~95% | 颜色/UV 缺失 |
| 时间分辨率 | ⚠️ 50 vs 180 Hz | 帧率受限 |
| Lamina 处理 | ⚠️ ~40% | 横向抑制+频带分离 |
| Medulla EMD | ❌ ~15% | 4方向运动检测 |
| Lobula 避让 | ✅ ~70% | 尚可 |
| Lobula Plate 光流 | ❌ ~10% | 旋转/垂直流缺失 |
| 颜色视觉 | ❌ 0% | 四色系统 |
| 小目标追踪 | ❌ 0% | LPLC/LC11 |
| 学习能力 | ❌ ~20% | 多巴胺强化学习 |
| 导航 | ⚠️ ~50% | CX 角编码 vs 网格地图 |
| 功耗 | ❌ 30–200 W vs 200 nW | 10⁹ 倍差距 |

> **核心结论**: Fly64 在当前工程降维模式下 (~1/50,000 的果蝇真实视觉维度) 已能完成 SM64 的基本游戏控制, 验证了 MaleCNS v1.0 连接组的潜力。但要接近果蝇的视觉行为多样性, 需要逐步引入: ① 4方向 EMD 运动检测 ② 颜色/UV通道 ③ 小目标追踪 ④ 多巴胺学习。FlyWire 实验已经证明, 天生连接组在 200 nW 上能够执行视觉模式识别——Fly64 的目标是将这个"能识别"扩展到"能自主导航、自适应学习"的水平。
