### 1.3 关键路径（Critical Path）

```
工业质检(6周) ──────────────┐
                            ├──→ 验证框架有效性 ──→ 保险核保(12周) ──→ 自动驾驶(12周)
机器人导航(10周) ────────────┘                                      ↑
                                                        量化交易(16周) ────┘
                                                        机械臂操控(12周) ──┘
多Agent系统(8周) ──── 独立并行路径 ────→ 可为其他领域提供分布式架构基础
```

**关键路径约束**:
- 工业质检和机器人导航是**最优先并行路径**，它们的最快交付验证Fly64迁移框架的商业可行性
- 保险核保依赖于框架验证的成功（缓解投资风险）
- 自动驾驶、量化交易、机械臂操控在Phase 3并行推进，共享流程输入编码和奖励重写经验
