## 1. 文章中的运动模式建议（提炼）

| 来源文献 | 运动模式建议 | 对 Fly64 的启示 |
|---|---|---|
| flyGNN（NeurIPS 2025，t2 §4.2） | 连接组作为递归消息传递网络，复现 **步态启动 / 直线行走 / 转向** 三类全身运动；神经元状态分析显示功能特化可通过低维嵌入读出 | 运动不应只有 4 个解码池；可用**线性读出**从不同神经元群体解码出更多运动原语 |
| Whole-Brain Graph Model（arXiv 2602.17997，t2 §4.3） | 图结构先验 + DRL → 多样化运动任务，样本效率高 | 新运动原语可用 dopamine-RPE（已有 MB）做在线塑形，不必重训练连接组 |
| Eon Systems（t2 §4.4） | 结构 + LIF，91% 行为准确率零训练；多种自然行为自主涌现 | 行为多样性来自**多样化读出**而非训练量 |
| MaleCNS 分布式控制（Nature 2026，t4 §7） | **VNC 中央模式发生器（CPG）** 独立于脑生成节律性行走；脑-VNC 分层：反射层→协调层→规划层（subsumption） | 增加一个"VNC 运动原语层"，把连续节律动作（游泳/爬行/拳击）交给 CPG，脑只发"启动/停止"门控 |
| MB 多巴胺 TD 学习（t4 §5） | DAN 计算 RPE，KC→MBON 可塑 = 生物 Q-learning | 每新增一个动作原语，配一条 MBON 列做成败学习（已有 forward/left/right/jump/explore 5 列骨架） |
| StonkFly（t2/t4） | 放电率差 → 多档离散动作（buy/sell/hold） | 证明从放电率**分组对比**可直接驱动离散按键，不限于模拟摇杆 |

## 2. 目前脑模型可控的运动能力（实测量化）

### 2.1 控制面（桥接协议上限）

`sm64ex-fly64.patch` 的 `fly64_bridge_read_controller()` 每帧只写入：
- `stick_x` / `stick_y`（模拟摇杆，-70~70，含 8 死区 + 低通滤波）
- `buttons`，且**强制只保留 A 键**（`buttons &= ~A_BUTTON` 后由 `jump_frames` 重新注入）——B 键、Z 键、Start 从不传递

### 2.2 神经解码面（模型输出上限）

`model.py` 仅 4 个下行解码池，共 **160 / 166,700 个神经元**（<0.1%）参与运动解码：

| 池 | 神经元 | 输出 | 说明 |
|---|---|---|---|
| forward (DNg100) | 60 | stick_y 0~70 | 前进 |
| turn_left / turn_right (DNa02/DNg13) | 40+40 | stick_x ±70 | 转向（含 TurnAdaptation 疲劳交替、CX 转向偏置、切向绕行偏置） |
| jump (DNp01/DNp10) | 20 | A 键 | 0.04 rate 门控 + 0.8s 冷却 |

### 2.3 行为层（级联后的实际动作集）

六级级联（dialogue→cliff_reflex→anomaly_reflex→escape→jump→steering）最终组合出的**全部可控动作**：

1. 直线行走（速度连续可调 0~70）
2. 左右转向（连续，含急转 ±60）
3. 单次/连跳（A 键，含跳跃爆发、下坠重置连打）
4. 后退（escape 相位 stick_y<0）
5. 交互确认（对话框场景的 A 键 press_a）

**即：马里奥的行为词汇 = {走、转、跳、退、确认}，5 个动作原语。**

## 3. 缺失的运动能力（按桥接/神经/行为三层归因）

### 3.1 桥接层缺失（B/Z 键根本传不进游戏）

| SM64 动作 | 所需输入 | 现状 |
|---|---|---|
| 拳击/踢腿/抓取（B） | B 键 | ❌ 桥接层被过滤 |
| 俯冲 dive（空中 B） | B 键 | ❌ |
| 蹲下/爬行（Z） | Z 键 | ❌ |
| **长跳 Long Jump**（跑动中 Z+A） | Z 键 | ❌ |
| **后空翻 Backflip**（蹲+A） | Z 键 | ❌ |
| **-ground pound 落地砸**（空中 Z） | Z 键 | ❌ |
| 踢墙跳 Wall Kick（贴墙时机 A） | 仅 A 键+时机 | ⭕ 理论可行，需墙壁接触感知 |
| 侧空翻 Side Flip（往返拉杆+A） | 仅摇杆 | ⭕ 理论可行，需转向反转检测 |
| 游泳上浮/加速（A 连打 / 摇杆） | A+摇杆 | ⭕ 半可控（水中有摇杆，缺节律性 A 连打 CPG） |
| 缓慢行走（摇杆小幅度） | 摇杆 | ⭕ 半可控（死区 ±8 抹掉了小速度档） |

### 3.2 神经层缺失（没有对应的解码池）

- 无 B 池、无 Z 池 —— MaleCNS 里还有大量未使用的下行神经元（DNa01、DNg09、DNa02 副群等）可作候选读出源
- 无**运动原语/节律发生器**：t4 §7 文献指出 VNC CPG 负责节律动作；Fly64 目前所有动作都是即时速率解码，没有"启动一个 200ms~2s 动作序列"的机制
- 无**水中/空中姿态感知**驱动动作切换（grounded / airborne / swimming 状态机缺失，pose 数据其实已有）

### 3.3 行为层缺失（README 已实证）

- 语义行为三重缺失（感知/认知/行为）：不会"拿钥匙再开门"——没有拾取/使用道具的原语（依赖 B 键缺失）
- 逃逸位移 0u（ramp_trap）：缺长跳/后空翻等**大位移脱困原语**
- 平台跳跃成功率受限（P2 后 65%）：缺踢墙跳、侧空翻等组合技

## 4. 按文章思路的扩展建议（优先级排序）

### R-A 桥接层解锁 B/Z 键（最小改动、最大收益）
仿照 `jump_frames` 的脉冲注入机制，在共享内存头加 `b_frames`/`z_frames`；Python 侧加两个解码池或先由 escape 级联直接驱动。**解锁：拳击、俯冲、落地砸、长跳、后空翻、爬行 6 类动作。**

### R-B 线性读出新增运动池（flyGNN 低维读出思路）
- 从未占用神经元群体训练/构造线性读出（reservoir readout 思路，t2 §4.5），映射到 B 池/ Z 池
- 每个 MBON 现有 5 列 → 扩展 `punch/dive/groundpound/longjump` 列，复用 dopamine 三因子增益规则做成败塑形（StonkFly 离散动作思路）

### R-C VNC CPG 运动原语层（t4 §7 分布式控制思路）
- 新建 `motor_primitives.py`：CPG 振荡器库（游泳连打节律、长跳的 Z→A 时序、后空翻的 Z→A、爬行慢速节律）
- 脑模型只发**门控信号**（"此处需要长跳"），时序由 CPG 自主完成 —— 与现有"反射层不占脑解码"的分层原则一致
- 触发源用已有信号：`stuck_ramp`+`cliff_tangent` → 长跳；`fallen` → 后空翻复位；`ground_angle` 水体检测 → 游泳 CPG

### R-D 动作状态机（NeuroMechFly v2 全身传感反馈思路）
利用桥接已有的 `pose`（x/y/z + 朝向）推断 grounded/airborne/swimming/wall 状态，作为 CPG 门控前置条件，避免空中误发 Z 长跳这类非法组合。

## 5. 预期效果对照

| 指标 | 现状 | 扩展后 |
|---|---|---|
| 动作原语数 | 5 | 12+（+拳/踢/俯冲/砸地/长跳/后空翻/爬行/游泳节律/踢墙跳/侧空翻） |
| 解码神经元占比 | 160 (0.1%) | ~400 (0.24%)，仍远低于连接组容量 |
| 斜坡逃逸位移 | 0u（5 次事件实测） | 长跳/后空翻 CPG 预期产生首个非零位移 |
| 锁门语义死角 | stuck 死循环 | B 键拾取钥匙原语是解耦语义缺失的第一步 |

## 6. 结论

文章的核心建议是：**连接组的运动多样性来自"多样化读出 + 分布式 CPG + 多巴胺塑形"，而非更大训练量**。Fly64 目前只用了连接组 0.1% 的神经元、桥接面 3 个自由度（x/y/A）中的 2.5 个，行为词汇被压到 5 个原语。按 R-A（解锁 B/Z 桥接）→ R-C（CPG 原语层）→ R-B（新池读出 + MBON 塑形）的顺序扩展，可以以最小改动把马里奥的可控动作从"走转跳"扩展到 SM64 动作表的主力集合，同时直接命中 EVO 记录的 ramp_trap 零位移和锁门死循环两大行为瓶颈。
