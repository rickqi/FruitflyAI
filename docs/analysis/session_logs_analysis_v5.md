## 4. 当前主要困境

> **本节的特殊价值**：三条**相互独立**的工作线（日志分析、自动化审计、实机验证）**收敛到了同一根因**。

### 4.1 🔴 困境一：自进化闭环**在结构上**无法自治修复（并行审计定性）

独立审计（`analysis-t2-evolution-pipeline-failure.md`）用真实命令回放，给出**六处同时断开**：

| # | 失效点 | 证据 |
|---|--------|------|
| 1 | **闭环根本没在运行** | 最后一次迭代写入是 **09-17 10:22:55**，审计时已停摆 **7 天**；无进程、无锁、无计划任务 |
| 2 | **没有能匹配该故障的 pattern** | 回放故障快照只命中 medium/low；**0 个 high/critical** |
| 3 | **最贴近的 pattern 被自己的"修复"改瞎** | `ramp_trap` 的条件键 `position_unchanged_30s` **全仓无生产者** → 结构上永不可达；该键比闭环死亡**晚 1 天**引入 |
| 4 | **生成的 fix 全是注释占位** | 19 条 fix 中 **16/19 可执行行数 = 0**；合计 7 行代码 vs 87 行注释 |
| 5 | **验证成功率恒为 0 且 fix 一次性** | 漏斗 `13728 iterations → 44159 findings → 11 fixes → 0 effective`；`has_fix()` 使 pattern 有了一条无效 fix 后**永不生成新 fix** |
| 6 | **脑参数自进化信噪比 ≈ 0** | 4.46 天 68 个试验，**41 个 delta 恰为 0.0**，只 commit 1 次（1.47%）|

> 这与我在 P0-1/t8 的发现**独立吻合**：当时我也发现 **19 条 fix_template 中 16 条为非结构化文本**（机器不可执行）。

### 4.2 🔴 困境二：自适应信号到不了"决定行为的变量"（本轮实机验证）

我在 2026-09-23 的实机验证中直接抓到：

```
教练写 turn_bias=0.8 / bold=20.0
  → 约 26s 后被 main.py 的 R31-fix12 安全钳位覆写为 0.25 / 10
  → 且自愈回写把钳位值持久化
  → 行为不变，且全程无任何遥测可见
```

**这正是用户抱怨「coach 建议未生效」的机制本体。**

### 4.3 ⭐ 三条工作线的**收敛**（本报告最重要的判断）

| 工作线 | 表述 | 层级 |
|--------|------|------|
| 并行审计 M1 | **信用分配断口**：决定行为的变量与所有自适应面不重叠 | 决策/输出 |
| 我的 P1 实测 | **教练建议被钳位吃掉**，到不了 `memory_ctrl.bold_turn_bias` | 参数/消费 |
| 并行审计 t2-#4 | **fix 全是注释占位**，EVO 产不出可执行修复 | 修复/产出 |

**三者是同一根因在不同层的表现**：

```
自适应信号（学习 / 增益 / 参数 / 教练建议 / EVO fix）
        │
        ├─ EVO 产出的 fix 不可执行（t2-#4）
        ├─ 教练参数被钳位吞掉（我的实测）
        └─ 决定行为的变量不读任何自适应面（M1）
        ▼
   行为不变  →  用户看到"改了很多，但马里奥还是转圈"
```

**这就是项目最核心的困境**：两周里大量工作都在**产生自适应信号**，但**信号到行为的通路是断的**。

### 4.4 🟡 困境三：观测层口径缺陷使"是否生效"无法判定

- 并行审计 M3：`stuck_score ≡ 1.0` 是**构造伪影**，早期报告引以为据的"卡死"证据**部分不成立**
- 我 P1-5 发现：`test_tunable_wiring` 的区间检查因一次无害重构**退化为恒过**
- 我 P1-1 之前：`/memory.json` **没有 `coach_applied`**，建议被钳掉无人可见

**共同模式**：**"机制存在、报告成功、无法生效"**（项目内部编号 EVO-066 缺陷族）。本轮已修若干例，但**该模式仍在复发**。

## 6. 一句话总结

**项目在两周里造出了大量"会学习、会调参、会自我修复"的机制，但实测与独立审计同时证明：这些信号到"决定马里奥行为的变量"之间存在断口 —— 教练的建议被钳位吃掉、EVO 的 fix 是注释占位、行为变量不读任何自适应面。**

**下一步最该做的不是再加一个自适应面，而是把"信号→行为"的通路打通，并让"是否生效"随时可观测。**
