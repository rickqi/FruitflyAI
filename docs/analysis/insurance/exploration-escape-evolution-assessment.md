## 2. 脱困能力

### 实现机制 (11层嵌套)

```
脱困优先级:
L1: CliffReflex (多帧确认, 50ms响应)
L2: ReflexController (4电路 stuck_ramp/oscillating/wall_stuck/micro_loop)
L3: Escape主流 (stuck_score > 0.8, 自适应阈值)
L4: ForcedBoldExplore (micro_loop > 60s → 强制突破)
L5: CX转向 + tangential detour (目标方向 + 悬崖切线)
L6: TurnAdaptation + breakout_drive (编织→前向突破, 0.35增益)
L7: Restlessness (对峙时间累积→前向驱动, 0.12)
L8: PitEscape振荡器 (地下→跳跃+前向, 5Hz)
L9: 场景危险识别 (熔岩→谨慎抑制, -0.06)
L10: LLM教练升级 (stuck > 60s → 外部咨询)
L11: Reflex→LIF桥接 (P4-1新, 网络参与决策)
```

### 异常态处理能力

| 异常态 | 机制 | 成功率 | README承认 |
|--------|------|:------:|:----------:|
| micro_loop(编织) | breakout_drive=0.35+P1-1改良 | 部分 | ✅ |
| circle_loop(转圈) | ground_angle门控+P1-1改良 | 有误触发 | ✅ |
| stuck_ramp(斜坡) | 自适应反射冷却+反驱 | 中 | ✅ |
| fallen(坠落) | 镜像转向+延长burst+P4-1 | 部分 | ✅ |
| 锁门死循环 | →LLM教练(60s)+习惯化 | **无法自解** | ✅ 已知局限 |

### 定量评估

| 指标 | 读数 | 意义 |
|------|:----:|------|
| escape_duration | 29s-164s (日志) | 逃逸耗时 |
| escape_distance | 多数~0u | 逃逸位移(无效) |
| health_score | 50% (监控) | 总体健康度 |
| reflex_effective | 10/18项无效(fix_catalog) | 反射有效性低 |

### 结论
脱困能力**机制丰富**(11层嵌套)但**实际效果有限**——fix_catalog显示10/18项fix判定ineffective, 逃逸位移多数~0u。breakout_drive增强(P1-1)和Reflex→LIF桥接(P4-1)是近期改进, 需真机验证。

### 进化有效性分析

```

  total: 18
  effective: 0    ← 从未有fix被判定有效
  ineffective: 10 ← 明确无效
  pending: 2      ← 待验证(fix_0006/0007)

根因: 验证窗口跨重启丢失 → P0-1已修复
但: 即使验证通过, fix_template = 发现→记录→人工执行
```

### 结论

## 4. 综合评级

| 维度 | 能力描述 | 评级 |
|:----:|---------|:----:|
| 🗺️ 探索 | 网格+新颖性+排斥+拓扑, 无垂直维度 | 🟢 **B+** |
| 🏃 脱困 | 11层嵌套机制, 但逃逸位移多数~0u | 🟡 **C+** |
| 🧬 进化 | 检测丰富、修复无效、链条已修 | 🟡 **C** |

### 核心矛盾

```
脱困的唯一最有效metric——"逃逸位移>0"——是77%异常态的核心病灶。
脑模型能做复杂的悬崖反射、斜坡脱困、LLM咨询,
但所有的技巧都无法将"转向动作"变为"有效位移"。
```

### 改善建议

| 方向 | 预期收益 | 难度 | 备注 |
|------|:--------:|:----:|------|
| **垂直维度扩展** | 支持多层关卡探索 | 中 | 50×50→50×50×5 |
| **逃逸位移优先** | 提高~0u比例 | 高 | 需要新的LIF注入策略 |
| **EVO自动fix** | 闭环修复 | 极高 | 需要代码生成能力 |
| **P0-1验证** | 效果待观察 | 低 | 刚修复, 需积累运行数据 |
