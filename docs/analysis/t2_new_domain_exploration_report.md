## 1. 新领域一：医疗诊断

### 1.1 嗅觉回路 → 生物标志物检测与疾病诊断

**对应模块**: `fly64/fly64/mushroom_body.py` — MushroomBody KC-MBON (2000KC+5MBON)  
**对应模块**: `fly64/fly64/memory.py` — MotionStateDetector (6状态异常检测)  
**对应模块**: `fly64/fly64/model.py` — FlyModel LIF推理引擎

**理论基础**:
- 果蝇嗅觉回路（触角叶→蘑菇体KC→MBON）在结构上等价于一个**高维稀疏编码+生物标志物检测器**：2000KC以5%稀疏度编码嗅觉输入，任何偏离健康模式的生物标志物组合都会产生不同的KC激活模式
- **Frontiers 2024**: 果蝇嗅觉系统的轻量级SNN已在神经形态芯片上实现硬件部署，证明从连接组到医疗硬件的可行路径
- **Journal of Engineering and Applied Science 2025**: 时空SNN+互信息特征选择在EEG癫痫分类中达到98.3%准确率——证明SNN在生物医学信号处理中的有效性
- **CCNeuro 2025**: 果蝇光学叶的无监督未来预测学习——证明连接组结构本身支持医疗时序预测（如ICU生命体征异常预警）

**具体映射**:

| Fly64 模块 | 医疗诊断映射 | 适配说明 |
|-----------|------------|---------|
| `MushroomBody` 2000KC+5MBON | 疾病标志物检测网络：KC为多模态生物标志物编码，MBON为疾病分类输出 | 替换128维场景签名为N维生物标志物特征（血液指标/基因表达/影像特征），5个MBON通道映射为5种疾病分类或健康/早期/中期/晚期/危急 |
| 三因子Hebbian `ΔW = η · R(t) · E_p · target` | 诊断模型的持续在线学习 | R(t)=病理确认的反馈信号（金标准诊断结果），target=正确诊断类别，E_p=时序归因窗口 |
| `ELIGIBILITY_DECAY = 0.8` | 病史的时间窗口衰减 | 表征历史诊断对当前评估的影响权重 |
| 5%稀疏KC编码 | 生物标志物组合的稀疏特征编码 | 高维稀疏编码天然适合"少量异常指标 = 特定疾病模式"的医学诊断逻辑 |
| 记忆巩固 (`consolidation_threshold = 0.6`, 最多10条) | 典型病例库的增量式积累 | 仅巩固"高诊断置信度"的病例模式作为参考 |
| 128维随机投影签名 | 病理影像的感知哈希（视角不变） | 替换场景图像为医学影像（X光/CT/MRI/OCT切片） |

**已有学术支撑**:
- **[IEEE 2025]** 时空SNN在癫痫检测中的应用: 事件驱动SNN天然适配EEG的时间稀疏性，能量效率比传统DNN低3个数量级

- **[Nature Methods 2024]** NeuroMechFly: 果蝇全链路控制验证了从感知到运动的完整闭环——在医疗场景中可理解为"从症状检测→诊断决策→治疗方案"的完整链路

**工程化成熟度**: 蘑菇体学习 4/5 · 输入编码替换（场景→医学特征）需重写 · 诊断类别映射需领域专家参与

- 快慢双轨反射（快路径硬编码规则 + 慢路径LLM推理）与临床决策流程同构：快速反应团队(RRT)触发标准（快路径）+ 主治医生会诊（慢路径）

- 电力系统负荷预测的本质是在不确定条件下估计**需求概率分布**——与CX环形吸引子维持航向置信度分布完全同构
- 智能电网的实时供需平衡可以建模为**多目标跟踪问题**：负荷跟踪 + 可再生能源输出跟踪 + 储能状态跟踪

**具体映射**:

| Fly64 模块 | 能源调度映射 | 技术对应 |
|-----------|------------|---------|
| `CentralComplex` 16列环 (22.5°/列) | 16个负荷区间的概率分布 | 每列 = 一个负荷水平的置信度（如0-5%/5-10%/.../75-80%负荷率） |
| `COMPASS_PERSISTENCE = 0.85` | 负荷预测的惯性平滑 | 历史负荷模式的平滑权重（高值=平稳电网，低值=快速变化的可再生能源并网） |
| 局部兴奋1.2 + 全局抑制0.25 | 负荷高峰聚集 + 区域间负荷平衡 | 局部高负荷区域的置信度增强 + 通过需求响应的全局抑制 |
| `GOAL_MEMORY_DECAY = 0.999` | 基线负荷的长期记忆 | 年/季度基础负荷的缓慢更新 |
| `MAX_STEERING = 0.15` | 调度的最大调整步长 | 每次调度指令不超过15%的功率调整 |
| `TurnAdaptation` 自发交替 | 可再生能源的多模式切换 | 光伏/风电/储能的动态组合轮换 |

**学术支撑**:
- **[AIMS Mathematics 2026]** 生物启发式神经形态框架: 在智能电网分布式故障检测和可再生能源优化中的应用已发表理论框架

### 2.2 LIF SNN推理引擎 → 可再生能源发电预测与负荷预测

**对应模块**: `fly64/fly64/model.py` — FlyModel LIF推理引擎

- 事件驱动SNN天然适配**非均匀采样**的电力数据（智能电表通常以15分钟间隔采样，但在波动时产生额外事件记录）
- **[IEEE 2025]** SNN在金融时间序列预测中的成功 = 同样适用于电力时间序列预测
- **[中国科学院 2025]** 基于非线性脉冲神经P系统的电力系统中长期负荷预测——直接证明脉冲网络在电力预测中的有效性

**具体映射**:

| Fly64 模块 | 能源预测映射 | 适配说明 |
|-----------|------------|---------|
| `Model.step()` 50Hz LIF推理 | 电力系统状态预测 | 替换视觉输入为电力参数向量（负荷/发电/电价/气温/风速等） |
| OU噪声 (`ou_theta=2.0`, `ou_sigma=0.10`) | 可再生能源输出的随机波动建模 | 保留OU参数，调节为可再生波动的OU(θ_wind, σ_solar) |
| 突触缓冲 (`synaptic_buf_decay = 0.65`) | 电力波动的衰减传播 | 捕获"负荷冲击"在电网中的传播和衰减效应 |
| 滑动窗口投票 (13帧) | 发电预测的多时段共识 | 保持滑动窗口，输出为各时段发电量预测值 |
| `MushroomBody` 三因子Hebbian学习 | 预测模型的在线自适应 | R(t)=预测误差反馈，学习率极低防止过拟合短期气象条件 |
| 记忆巩固 | 典型气象模式库 | 仅巩固"高置信度"的发电预测匹配模式 |

**工程化成熟度**: 推理引擎 5/5 · 输入代替（视觉→电力参数）需重写 · 预测输出层需扩展
