## 1. 大规模LIF脉冲神经网络推理引擎

### 技术实现
- **核心**: `FlyModel` 类 (`model.py`) 封装从MaleCNS v1.0缓存的连接组权重，构建CSC稀疏矩阵 (151.9M边)，实现Leaky Integrate-and-Fire (LIF) 神经元模型
- **参数**: `dt = 0.020s` (50Hz) | `tau_m = 0.100s` | `threshold = 1.0` | `reset = 0.0`
- **增强机制**:
  - Ornstein-Uhlenbeck噪声 (全局+4通道电机): 模拟生理波动，提升深层网络神经元利用率
  - 突触缓冲 (`synaptic_buf_decay = 0.65`): 模拟神经递质持续性和被动电缆传播，改善信号传播
  - 多巴胺门控增益调制 (`DopamineGainController`): 5通路 (视觉/前进/转向/跳跃/循环) 增益缩放，不修改固定连接组
- **效率优化**: 完全向量化numpy/scipy操作；电机解码通过滑动窗口投票 (13帧历史)，非阈值决策

### 工程化成熟度: 5/5 (生产级)
- 已经过数千小时的闭环SM64验证
- 确定性随机种子 (`seed=64`) + 精确回放验证 (`replay.py`)
- 完整的缓存加载/校验体系

### 泛化潜力: ★★★★★
- **输入无关性**: 引擎接收任意维度输入向量 (当前1536维视觉)，可适配其他传感器模态
- **输出通用性**: 电机解码机制 (前向/左转/右转/跳跃) 可直接映射到任意连续/离散动作空间
- **噪声策略通用**: OU噪声 + 突触缓冲是神经形态计算的通用增强技术

### SM64耦合度: 低
- 电机输出名称 (forward, turn_left, turn_right, jump_nodes) 与SM64动作对应，但解码逻辑和注入接口 (`inject_currents`) 完全通用
- 输入映射需要重新校准，但引擎无需修改

## 2. 实时多模态视觉感知管道

### 技术实现
- **球面复眼**: `SphericalRetina` (`retina.py`) 实现270°视场角 × 144°垂直覆盖的6面cubemap采样，模拟MaleCNS光轴柱排列
- **1536个采样点**: 每个采样点通过7权重锥形采样实现抗锯齿
- **ON/OFF/持续通道**: 帧差分解为正瞬变/负瞬变/滑动窗口对比度
- **颜色视觉**: 5通道编码 (R/G/B/UV近似/HSV) + 红-绿/蓝-黄拮抗通路
- **4方向基本运动检测器 (EMD)**: T4 (ON) + T5 (OFF) 方向的Hassenstein-Reichardt相关器，4个基本方向
- **HRC运动真值**: 独立于EMD的第二个运动检测通道 (基于原始亮度)，提供LC4式逼近响应
- **边缘方向检测**: 4方向边缘能量 (0°/45°/90°/135°) 通过相邻晶格差异
- **小目标跟踪**: 中心-环绕拮抗 → 连通分量标记 → 匈牙利匹配卡尔曼滤波多目标跟踪
- **场景签名**: 128维随机投影 + L2归一化的视角不变场景指纹
- **地形分类**: 16扇区光流分析 → 8种地形类型 (悬崖/水域/走廊/墙壁/开阔/森林/室内/混合)
- **颜色方位直方图**: 8方位带×多通道色相分析

### 工程化成熟度: 5/5 (生产级)
- 所有感知信号经过数轮演进迭代验证 (EVO R7/R9/R11/R14)
- 精确的自我运动分离 (heading_rate补偿)
- 多帧确认机制 (悬崖10帧/对话框12帧)

### 泛化潜力: ★★★★★
- **通用视觉输入**: 管道接受任意RGB帧 (256×384 × 3 cubemap)，不限于游戏画面
- **生物启发特征**: ON/OFF/EMD/边缘方向/颜色拮抗都是通用视觉基元，适用于自主导航/检测/避障
- **光流分析**: 时间-接触 (τ) 估计、膨胀检测、扇区化光流是机器人学中的标准技术

### SM64耦合度: 中
- 悬崖检测的 `lower_field_green`、天空的 `sky_blue_index`、熔岩的 `danger_red_index` 针对SM64色彩域微调
- 对话框检测针对SM64特定UI模式
- 地形分类的阈值校准与SM64关卡风格相关

**解耦路径**: 色彩域重校准 + 地形模型替换即可通用化

## 3. 联想学习与可塑性 (蘑菇体 KC-MBON)

### 技术实现
- **架构**: `MushroomBody` (`mushroom_body.py`)
  - 2000个Kenyon细胞 (KC)，5%稀疏编码 (100/2000活跃)
  - 5个MBON输出通道 (前向/左转/右转/跳跃/探索)
  - 随机固定投影: 128维场景特征 → 2000维KC (种子64，可复现)
- **三因子Hebbian可塑性**: ΔW = η · R(t) · E_p · target → 多巴胺门控突触修改
- **资格痕迹**: 逐帧衰减 (`ELIGIBILITY_DECAY = 0.8`)，5帧可塑性窗口
- **记忆巩固**: KC活动痕迹 (200帧历史) + 多巴胺事件记忆 (20事件) + 巩固阈值 (`0.6`)，最多10条巩固记忆
- **并行增益通路**: `DopamineGainController` (`gain_modulation.py`) 通过5通路增益缩放实现神经调节代理

### 工程化成熟度: 4/5 (验证级)
- 严格数学框架：可塑性规则 + 权重边界 [-1, 1] + 平滑多巴胺信号 (`alpha = 0.3`)
- 防止灾难性遗忘 (`LEARNING_RATE = 0.001`)
- 缺少独立评价协议（学习效果通过整体游戏表现间接评估）

### 泛化潜力: ★★★★★
- **通用学习框架**: 场景签名→KC→MBON架构可重用于任意序列决策任务（机器人控制/导航/推荐）
- **三因子规则通用**: 多巴胺门控可塑性是神经形态计算的黄金标准
- **巩固机制**: 可应用于任何需要经验积累的场景

### SM64耦合度: 低
- MBON输出 (前向/转向/跳跃/探索) 是通用动作基元
- 学习信号 (多巴胺) 来自通用成功/失败检测，非游戏特定

## 4. 空间导航与路径积分

### 技术实现
- **中央复合体 (CX)**: `CentralComplex` (`central_complex.py`)
  - 16列环形吸引子航向罗盘: 22.5°/列，`COMPASS_PERSISTENCE = 0.85`
  - 局部兴奋 (`1.2`) + 全局抑制 (`0.25`) 的吸引子动力学
  - 目标方向记忆: 新型方向跟踪，`GOAL_MEMORY_DECAY = 0.999`
  - 转向偏差: 航向-目标比较 + 光流不对称 + 新型方向 → `MAX_STEERING = 0.15`
- **空间记忆**: `MemoryController` (`memory.py`, 2037行)
  - 场景数据库：基于余弦相似度的场景匹配（128维签名）
  - 50×50网格位置编码（仿海马体空间记忆）
  - 路径积分: 里程计→网格坐标 (heading_rate积分失败检测)
  - 锚点路径积分: 被成功/失败标记的场景引用点
- **转向适应**: `TurnAdaptation` 实现自发交替行为，防止振荡陷阱
- **运动自立**: 自我运动分离 → 真实世界的不对称性

### 工程化成熟度: 4/5 (验证级)
- 环形吸引子罗盘经过理论验证且实现鲁棒
- 目标记忆有缓慢衰减（非永久）
- 空间记忆的路径积分在SM64中面临挑战（非线性映射）

### 泛化潜力: ★★★★★
- **罗盘-目标架构**: 昆虫启发的导航框架是机器人学的标准范式
- **场景匹配**: 随机投影 + 余弦相似度是高效SLAM方案
- **路径积分**: 直接可迁移到物理机器人（轮式/腿足）

### SM64耦合度: 中-低
- 空间网格坐标映射到SM64游戏坐标（非线性），但算法本身通用

## 5. 自主异常检测与反射回路

### 技术实现
- **StuckDetector**: (`memory.py`) 三路独立信号检测 (视觉能量/游戏帧/电机速率) + Y轴异常 → `stuck_score ∈ [0, 1]`
- **CliffDetector**: 多帧确认 (5帧窗口, 3帧确认阈值) + 滞环 (进入/退出阈值不同)
- **场景变化检测**: `SceneMemory` 30帧环形缓冲 + 3σ统计异常
- **7种异常状态**: 包括 stuck / fallen / flow_anomaly / cliff / scene_change / dialogue / local_motion
- **4类反射动作**: `ReflexController` (reflex circuit)
  - 逃离 - 转向开放空间
  - 悬崖回避 - 180°急转
  - 跌落恢复 - 跳跃爆发
  - 振荡突破 - 冲破转向回路疲劳
- **快慢双轨**: 反射直接注入电流 (快) vs LLM咨询策略调整 (慢)

### 工程化成熟度: 5/5 (生产级)
- 多帧确认 + 滞环消除噪声触发
- 200个逃离事件环形缓冲，用于事后分析
- 经过大量SM64场景验证

### 泛化潜力: ★★★★★
- **通用异常框架**: 多信号粘滞检测 (视觉/帧/速率) 可迁移到任何时序系统
- **反射回路**: 快速避障/边界检测/跌落恢复是机器人的核心行为
- **场景变化检测**: 直接适用于环境监控/安全系统

### SM64耦合度: 低
- 异常触发信号 (temporal_energy, forward_rate) 测量通用量
- 反射行为 (逃离/悬崖回避/跌落恢复) 适用于任何运动主体

## 10. 跨进程mmap桥接协议

### 技术实现
- **SharedBridge** (`bridge.py`): 共享内存mmap (64+384*256*3+320*240*3 ≈ 701KB)
- **顺序锁 (seqlock)**: 无锁的单一生产者/单一消费者mmap读取
  - 有偶数/奇数的读写门控
  - 3次重试抵御撕裂读
- **心跳检测**: 基于 `CLOCK_MONOTONIC` 的时间戳 (`TimeSpec` 分辨率)
- **格式**:
  - Header: 128字节 (魔数/版本/帧序号/控制序号/启停/时间戳/x/y/按键)
  - Frame: 384×256×3 ≈ 294KB
  - Screen: 320×240×3 ≈ 230KB
- **冻结检测**: `SeqlockWatchdog`: 帧序号超过5秒不增加 → `stale`
- **平台适配**: 平台特定的内存屏障 (macOS OSMemoryBarrier/Linux TSO免屏障)

### 工程化成熟度: 5/5 (生产级)
- 已在macOS + Linux (WSL2) 上验证
- 撕裂读保护 + 心跳 + 冻结检测
- 零拷贝：脑模型直接读mmap，无需网络栈

### 泛化潜力: ★★★★☆
- **实时控制桥接**: 适用于任何需要低延迟控制的应用（机器人/游戏/嵌入式）
- **平台限制**: 不可用于Windows (当前桥接仅支持macOS/Linux)
- **协议通用性**: 可扩展为任意仿真器↔控制器接口

### SM64耦合度: 中
- 按键映射 (A_BUTTON/B_BUTTON) 专为N64/SM64设计
- 姿态数据格式 (4个浮点数+游戏帧+渲染耗时) 与SM64对齐

**解耦路径**: 按键映射抽象 + 姿态格式标准化 → 通用控制协议
