## 1. 三个候选方向的生物基础依据

### 1.1 小目标追踪 (LPLC1/2 + LC11 等效)

| 维度 | 依据 |
|------|------|
| **生物回路** | 果蝇 Lobula Plate → Lobula Columnar (LPLC1/2) 和 LC11 神经元专门检测运动小目标 |
| **感受野特性** | LC11 感受野 < 5° (1–3 小眼)，LPLC1/2 约 10–20° (3–6 小眼)，中心-外周拮抗结构 |
| **功能角色** | 追逐雌性果蝇（空中拦截算法）、躲避小型天敌、跟踪同类 |
| **运动选择性** | 对小运动目标强烈响应，大视场运动被抑制（中心-外周拮抗天然滤波） |
| **神经解剖学** | LPLC1 投射到中脑下降神经元，直接驱动前肢转向/拦截——这是果蝇自身的追逐回路 |

**Fly64 实现依据**：`retina.py` 已包含 `compute_small_targets()` 的完整实现，包括中心-外周拮抗（α=1.2）、连通域标记（8-连通 scipy ndimage）、动态阈值（mean+2σ）。`model.py` 有 `TargetTracker` + 匈牙利匹配卡尔曼滤波、拦截时间估计和行为调制规则。**核心算法已完成，但 LIF 网络行为调制通道（split-injection fix）尚未验证**。

### 1.2 颜色/UV 通道 (R7/R8 等效)

| 维度 | 依据 |
|------|------|
| **生物回路** | 果蝇四色视觉：R7(Rh3/Rh4, UV≈340nm) + R8(Rh5 蓝≈440nm / Rh6 绿≈520nm) + R1-R6 宽谱运动通道 |
| **颜色处理层级** | Medulla Ct1(长-短波拮抗)、Ct2(UV-蓝/绿拮抗)、Tm5c/Tm20 投射到 Lobula 进行颜色特征检测 |
| **功能角色** | 趋光性(UV 优先)、花卉觅食(UV 反射模式)、昼夜节律、颜色辅助运动检测 |
| **神经解剖学** | 颜色通路从视网膜经 Medulla Ct 细胞到 Lobula 视小球，独立于运动检测通路 |

**Fly64 实现依据**：`retina.py` 已包含完整的 `encode_color()` → RGBA 四通道 + 拮抗通道 + HSV + `sky_blue_index` + `danger_red_index` + 8 扇区色相分布。`model.py` 驱动公式已融合红/UV/绿显着项。`color_signature=True` 时签名投影使用 5 通道（128×7680 矩阵）。**当前已实现状态 ≈95% 完成，仅场景签名兼容性和验证缺失**。

### 1.3 多巴胺调制学习 (Mushroom Body 等效)

| 维度 | 依据 |
|------|------|
| **生物回路** | 果蝇蘑菇体：PN(投射神经元)→KC(肯扬细胞, 2000个, 5%稀疏编码)→MBON(34路输出) |
| **可塑性机制** | 三因子赫布学习：前突触KC×后突触MBON×多巴胺门控。FlyWire 证明硬接线连接组 + 多巴胺调制成对识别 |
| **功能角色** | 联想学习、场景-价值关联、趋近-回避行为决策 |
| **多巴胺来源** | PAM(正奖赏)、PPL1(负惩罚)——奖赏预测误差(RPE)编码 |

**Fly64 实现依据**：`mushroom_body.py` 是一个独立的模块（约 650 行），包含完整的 `MushroomBody` 类：
- 2000 个 KC，5% 稀疏激活
- 三因子学习规则（η=0.001），适应学习率，稳态缩放
- 代理奖赏信号计算（场景新颖性/前进/访问新单元 → 正奖赏；卡住/坠落 → 负惩罚）
- 历史缓冲区 + 熟悉度信号 + 记忆巩固（t7）
- `model.py` 已实例化 `MushroomBody` 并包含 MBON→运动池电流注入（增益=0.35），`_compute_dopamine()` 代理奖赏功能，及 `DopamineGainController`（通路增益调制）

**当前状态**：**模块已基本实现**，但在验证过程中暴露了几个已知问题（P0-2 MBON 饱和度、P0-3 阈值错误），见 `brain-comprehensive-review.md` 及其 v2 版本。

## 2. 实现复杂度与代码影响范围

### 2.1 影响范围对比

| 方向 | 受影响文件 | 需修改行数 | 新增模块 | 算法复杂度 |
|------|----------|-----------|---------|-----------|
| **小目标追踪** | `retina.py`, `model.py` | ~120 行新增，30 行集成 | 无（全部内嵌） | O(N + K³)：连通域 + 匈牙利匹配 |
| **颜色/UV 通道** | `retina.py`, `model.py` | ~150 行新增 | 无 | O(N)：逐像素矢量运算 |
| **多巴胺调制学习** | `mushroom_body.py` (新), `model.py`, `main.py` | ~650 行新模块 + 50 行集成 | `MushroomBody` 类 | O(KC×MBON)：2000×128 + 2000×5 矩阵乘法 |

### 2.2 当前实现细节

**小目标追踪**：
- ✅ `compute_small_targets()` 完整实现，使用 8-连通域 scipy ndimage.label 加速
- ✅ `TargetTracker` 类 + `TrackState` 数据类（匈牙利匹配/常量速度卡尔曼滤波）
- ✅ 自运动门控（`heading_rate > 1.0` 时抑制）
- ✅ 拦截时间估计 + 行为调制规则（跳跃/回避/外围回避）
- ❌ LIF 分裂注入修复尚未验证——电流直接写入 `self.v[pool]`，但 `step()` 中的 `raw_x/raw_y` 逻辑覆盖了网络输出，导致拦截定时与实际动作不匹配

**颜色/UV 通道**：
- ✅ `encode_color()` → 12 个输出通道（R/G/B/UV_appx/H/S/V/拮抗 RG/BY/UVL/对比度）
- ✅ `compute_flow()` 使用 `sky_blue_index`、`danger_red_index`、8 扇区色调分布
- ✅ `encode_retina()` 中驱动公式包含 `red_sal`、`uv_sal`、`green_sal`
- ✅ 5 通道颜色签名投影（`color_signature=True`）
- ❌ 反向兼容：旧场景数据库签名在启用颜色签名时失效——需要重建或迁移
- ❌ 行为调制规则（6a/b/c）已编码，但实际效果尚未量化评估

**多巴胺调制学习**：
- ✅ `MushroomBody.encode()` → 从场景签名进行 KC 稀疏编码
- ✅ `set_dopamine()` → 指数平滑 + 可塑性窗口触发
- ✅ `update_weights()` → 三因子赫布学习 + 自适应学习率 + 稳态缩放 + 恢复噪声
- ✅ `warm_start()` → 基于签名的巩固记忆转移
- ✅ `consolidate_anomaly_resolution()` / `recall()` → 记忆巩固与检索
- ✅ MBON → `model.py` 中的运动池电流注入（增益 = 0.35）
- ⚠️ P0-2 MBON 饱和：所有 9 个通道在 tanh≈±1 处持续饱和，阻止进一步学习和差异化响应（见 `p0-2-mbon-saturation-analysis.md`）
- ⚠️ P0-3 阈值错误：`anomaly_state_name` 从 `"idle"` → `"fallen"` 时出现 1-tick 延迟，导致不正确的多巴胺定时（见 `p0-3-threshold-bug-analysis.md`）
- ⚠️ `DopamineGainController` 激活后降低总体网络活动——通路增益可能太低，实际调制无法穿透 LIF 阈值

### 2.3 代码影响范围汇总表

| 文件 | 小目标追踪 | 颜色/UV | 多巴胺学习 |

## 4. 视网膜/髓质管线瓶颈与扩展能力

### 4.1 当前管线架构

```python
encode_retina()  pipeline:
  retina.sample(rgb)          → frame (1536,)      [0.02 ms]
  compute_flow(frame):                             [0.12 ms]
    ├── encode_on_off()       → ON/OFF/sustained
    ├── encode_color()        → 12 color channels
    ├── compute_emd()         → 10 EMD directions
    ├── compute_hrc()         → HRC motion + looming
    ├── compute_small_targets() → targets list
    ├── edge_orientation()    → 4 edge orientations
    ├── compute_ground_angle()
    ├── compute_door_frame()
    └── tau estimation
  drive computation                               [0.01 ms]
  scene memory update                              [0.005 ms]
  MB encode                                         [0.01 ms]
  Total retine pipeline                            [~0.18 ms]
```

### 4.2 瓶颈识别

| 瓶颈 | 严重性 | 描述 |
|------|--------|------|
| **B1. 多目标匈牙利匹配** | 低 | O(K×D²) 成本矩阵构建在 20+ 个目标时可达 ~200μs——但 SM64 场景通常仅 0-5 个目标 |
| **B2. 颜色签名投影** | 低 | 128×7680 投影 = 983K MAC——~5μs 在 numpy 上 |
| **B3. 50Hz 帧率墙** | **高** | Mario 的游戏逻辑帧率为 50 Hz——这是仿真器的限制，而非视网膜代码的限制。视网膜/大脑处理速度是 180-200 Hz |
| **B4. LIF 分裂注入修复** | **关键** | `step()` 中的 `raw_x`/`raw_y`/`jump` 逻辑目前覆盖了所有神经元的动作调制——这意味着视网膜信号经过整个 LIF 网络的处理但最终仍被 Python 侧规则所取代 |
| **B5. 无真实生物光学校准** | 中 | 当前球面采样是工程近似值，而非从 MaleCNS 真实光学特性测量——对于生物逼真度要求严格的 FlyGym 部署来说很关键 |

### 4.3 扩展能力评估

| 扩展方向 | 瓶颈 | 缓解方案 | 预计开销 |
|---------|------|---------|---------|
| **更多扇区** (8 扇区 → 16 扇区) | 无 | 已预建 16 扇区掩码 | 0 |
| **更高帧率** | 仿真器 50 Hz | 增加仿真器帧率需改桥接层 | 高 |
| **颜色通道扩展** | 无 | `encode_color()` 已支持任意通道 | 低 |
| **额外 EMD 方向** (8 方向) | 低 | `ElementaryMotionDetector` 可扩展，但 4 方向已达理论极限 | 低 |
| **更宽的视场** | 无 | 270° 已是物理极限 | 0 |
| **中心凹/锐利区采样** | 中 | 需修改 `visual_pixels` 以支持非均匀分布；当前为均匀采样 | 中 |

## 6. 推荐方向及分步执行计划

### 6.1 核心推荐：**颜色/UV 通道作为下一个落地方向**

**理由**：
1. **实现状态**：≈95% 完成——`encode_color()`、驱动公式、`sky_blue_index`/`danger_red_index`、5 通道签名均已实现并集成。唯一缺失的部分是启用签名并验证行为影响。
2. **无依赖项**：无需修复 LIF 分裂注入即可验证——颜色调制通过两种机制运行：
   - 机制 A：`drive` 公式增强直接刺激视觉神经元
   - 机制 B：`step()` 中基于签名的 `raw_x`/`raw_y` 调制
3. **风险极低**：保守系数（红=0.15，UV=0.10）+ `np.clip()` 确保障稳定。
4. **下游协同效应**：颜色是果蝇视觉的基础通道——对小目标检测的信噪比和蘑菇体学习的签名鉴别力均有益。

### 6.2 分步执行计划

#### 阶段 0（准备/验证）：颜色管道验证（1 天）

| 步骤 | 操作 | 验证标准 |
|------|------|-----------|
| 0.1 | 检查 `color_signature=True` 是否导致场景签名碰撞 | `compare_signatures()` 对相似但颜色不同的场景输出低余弦距离 |
| 0.2 | 量化 `danger_red_index` 对熔岩/敌人检测的影响 | 在 LavaLand 中测量假阴性率 |
