# 参照方案分析：MaleCNS 连接组驾驶 TrackMania 的"复眼+视叶+蘑菇体"视觉方案

> 2026-09-12 · 基于 Google 系公开演示截图分析（MaleCNS v1.0，6,378 神经元，60 分钟试错学习赛道）。
> 目的：对照本项目（MaleCNS 166,700 神经元 + SM64）提取视觉架构的可借鉴设计。

## 一、该方案的四层架构（从截图拆解）

### 1. 多复眼全景渲染（left eye / front / right eye）
- 截图下半部显示三区分离的**复眼视图**：左眼/正前/右眼各自独立渲染
- 正前区六角小眼排列**致密**（白色高亮区=高分辨率锐利区），周边区稀疏渐暗
- 这复刻了果蝇复眼的真实特征：**前部锐利区（fovea/acute zone）+ 周边低密度区**，而非均匀球面采样
- 底部标注：`eye + optic lobe + brain shown as the fly would see the lap` —— 视觉链路全程按"果蝇会怎么看"渲染

### 2. 显式视叶（Optic Lobe）微回路 —— 关键差异点
截图头部列出明确的细胞类型链路：`L1/Mi1 → T4/T5 → HS/VS` + `LC, LPLC`：

| 回路 | 功能 | 对应我们增强评估 |
|------|------|----------------|
| L1/Mi1 | Lamina 单极细胞，ON/OFF 信号前处理 | 我们已有 ON/OFF 通道 ✅ |
| **T4/T5** | **元素运动检测器（EMD）**：ON/OFF 分流后四方向塔式排列，产生局部方向运动向量 | 正是我们的 E1（HRC 方向流）——**该方案已实现，验证了可行性** |
| **HS/VS** | 宽场切向细胞：汇聚 T4/T5 向量为**全场光流状态**（平移/旋转场分解） | 我们的 E1 后半——自运动分离的生物原生解 |
| **LC / LPLC** | **威胁/目标检测器**：LC4 = looming 特化（截图右下 `LC4 loom L/R` 左右双通道曲线）、LPLC = 逃避威胁 | 我们的 E2（STMD 小目标）+ 现有 τ looming 的种群化升级 |
| DN | 下降神经元：视觉决策→运动命令 | 我们的 160 运动命令神经元 |

**核心洞察**：它不是让 6,378 个通用 LIF 神经元自己"学出"运动检测，而是**按连接组解剖结构显式搭建视叶微回路**——T4/T5 的四方向塔、HS/VS 的汇聚、LC 的特化检测都是结构性先验。

### 3. 蘑菇体（Mushroom Body）多巴胺学习 —— 果蝇的"可训练本能"
底部标注完整给出学习机制：
```
PN→KC→MBON wiring from the connectome,
KC→MBON synapses depressed by dopamine
(PAM reward / PPL1 punishment, reward-prediction error)
```
- **PN→KC**：嗅觉/多模态输入经投射神经元随机高维扩张到 Kenyon Cell（稀疏编码），接线来自连接组实测
- **KC→MBON**：MBON 输出**接近-回避价值**（截图右侧 `MBON value (approach-avoid)` 曲线）
- **DAN 多巴胺**：PAM=奖励 / PPL1=惩罚，按**奖励预测误差（RPE）**压低 KC→MBON 突触——这是果蝇的联想学习
- 60 分钟试错即学会赛道 —— 因为**结构对了，学习就快**

### 4. 全链路可视化
右下角 `LC4 loom L/R`、dopamine PAM+/PPL1- 实时曲线 + 赛道图路线/轨迹 —— 与我们刚建成的因果时间轴理念完全一致，但可视化的对象是**神经回路级变量**（每个回路一个通道）。

## 二、与本项目的对照

| 维度 | 该方案 | 本项目 | 差距/启示 |
|------|--------|--------|----------|
| 神经元规模 | 6,378（精选任务相关） | 166,700（全连接组 LIF） | **结构 > 规模**：它显式搭视叶回路，我们期望通用 LIF 网络自发涌现——这正是我们"brightness, not flow"缺陷的根源 |
| 运动检测 | T4/T5 EMD 显式实现（4 方向塔） | 亮度差分近似 ❌ | 印证增强评估 E1 的必要性与可行性 |
| 威胁检测 | LC4 looming 种群（左右通道） | 单一全局 τ 标量 | 我们的 E2/τ 升级方向：种群化+方位化 |
| 光流状态 | HS/VS 宽场汇聚 | heading_rate 硬编码补偿 | E1 完成后自运动分离的原生解 |
| 学习 | MB 多巴胺 RPE（KC→MBON 抑制） | 无学习；六级固定级联 + EVO 外环代码进化 | **最大可借鉴点**：MB 学习是果蝇**自身能力群**内的学习，可在不违反分层原则下引入 |
| 采样几何 | 前部锐利区 + 周边稀疏（多区复眼） | 均匀球面 270° | 多复眼分区采样可提升正前分辨率而不增总预算 |
| 可视化 | 回路级变量曲线（LC4/MBON/DAN） | 因果时间轴（决策级） | 理念相同，粒度可下沉到回路通道 |

## 三、对本项目的具体建议（更新进增强路线）

### V1. 采纳 T4/T5 显式视叶（强化 E1）
- 不做通用 HRC 独立模块，而是按解剖搭**方向塔**：L1（ON）/Mi1（OFF）分流 → 4×T4（亮边运动）/4×T5（暗边运动）→ 汇聚为 8 方向×16 扇区局部运动向量场
- 输出：`sector_flow[16×8方向]`，HS/VS 层做全场积分得平移/旋转分量 → 替换 heading_rate 硬补偿

### V2. LC4 looming 种群化（升级现有 τ）
- 全局 τ → 左右/上下多通道 looming 检测种群（每扇区一个 LC4 通道），因果时间轴可画 `LC4 loom L/R` 双曲线
- 悬崖/碰撞归因从"标量阈值"变"种群竞争"，误报率下降且因果卡解释力更强

### V3. 引入蘑菇体价值学习（结构性新增，果蝇自身能力群内）⭐
- 解决 escape 死循环的**生物学正解**：不做固定优先级覆盖，而让 MB 学习"该状态下哪个动作价值高"
- 工程 minimal 版：KC 层=场景签名的稀疏高维重编码（SceneDatabase 已有 128 维签名），MBON=每动作族的接近-回避价值，DAN=RPE（如 coverage_rate 变化、stuck 解除）
- 与 EVO 外环的关系：EVO 改代码（慢学习/发育），MB 改突触权重（快学习/经验）——两者互补，且 MB 学习完全在果蝇自身能力群内，符合分层原则
- `decision_source` 可新增 `mbon_value` 归因通道，因果卡直接显示"习得价值在驱动"

### V4. 复眼前部锐利区（多复眼分区采样）
- 正前 ±30° 采样密度 ×4，周边不变——总预算不变，正前目标分辨率提升
- 与 E2 STMD 配合：锐利区小目标检测最有效

### V5. 回路级可视化扩展
- 因果时间轴新增泳道：`LC4 loom L/R`、`MBON value`、`HS/VS flow state`——把神经回路变量纳入因果链（每条泳道一个回路，与 decision_source 审计同构）

## 四、能力边界重申

该方案证明：连接组驱动的果蝇脑**不需要 LLM 也能学会任务**——前提是把视叶/蘑菇体的结构先验显式建出来，再用多巴胺 RPE 经验学习。这使更多能力归入"果蝇自身能力群"（价值学习），缩小对训练教官层的依赖——教官层只剩真正的语义任务（"这一关需要钥匙"），而"怎么绕过去"可以由果蝇脑自己学会。
