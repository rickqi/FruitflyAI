# 复眼视觉识别能力增强评估

> 2026-09-12 · 基于 `fly64/retina.py`（SphericalRetina）实际实现与果蝇视觉神经科学参照。
> 架构原则：所有增强属于**果蝇自身能力群**（具身本能回路），语义理解仍归训练教官层（见 README 分层原则）。

## 一、当前能力盘点（已实现 ✅）

| 能力 | 实现 | 参照生物学回路 | 局限 |
|------|------|--------------|------|
| 球形采样 | 1,536 小眼 × 7 锥形高斯采样，270°×144° | 复眼小眼列 | 采样稀疏（图集 294,912 像素→0.5%） |
| 亮度/时域/颜色三通道 | drive = 0.45·lum + 1.6·temporal + 0.25·color | 光感受器 R1-R6/R7/R8 | 颜色仅绿色对比，无 UV 通道 |
| ON/OFF 分离 | 帧间亮度瞬变正/负通道 | Lamina L1/L2 单极细胞 | 全局标量+逐细胞，无空间配对 |
| 持续通道 | 5 帧滑窗对比度 | 慢速适应 | 窗口固定，无尺度金字塔 |
| 边缘方向能量 | edge_0/45/90/135（细胞对差分） | 视叶定向简单细胞 | 仅 4 方向、单尺度 |
| 16 扇区能量 | 8 方位×上下带亮度均值 | 视叶柱状组织 | 只有亮度均值，无运动方向 |
| 光流三信号 | left_right_asymmetry / center_expansion(looming) / lower_field_green(cliff) | 视叶大场运动通路 | **亮度均值差 ≠ 真实运动向量**（注释已自认 "brightness, not flow"） |
| τ 接近时间 | 径向发散度倒数 | looming 检测器→巨纤维(GF) 逃避 | 单一全局 τ，无对象分割 |
| 地形分类 | 16 扇区流模式→8 类（wall/ramp/cliff/corridor/open_flat/forest_edge/door_frame/sky） | —（工程层） | 阈值规则，无学习 |

**核心短板**：当前"光流"实为**亮度能量差分**，不是真正的方向选择性运动检测。果蝇之所以是运动计算大师，在于视叶（Optic Lobe）四级神经柱的**局部运动向量**计算。

## 二、增强路线（按生物学参照 + 工程性价比排序）

### E1. 真正的方向选择运动检测（HSE/T4/T5 参照）⭐ 最高优先级
- **现状**：`left_right_asymmetry = (left_energy - right_energy) / total` 是亮度差，平移纹理不动时误判，相机自转时与目标运动混淆（已用 heading_rate 硬解自运动分离，属补丁）
- **增强**：经典 **Hassenstein-Reichardt 相关器（HRC）**——逐小眼对做 `.delay(temporal) × spatial_neighbor` 相关，得到逐细胞局部运动向量（右移/左移/上/下 4 个方向通道）
- **实现**：retina.py 已有 `_edge_pairs`（细胞邻接对）与 `_prev_lum`，HRC 只需对每对做一次延迟乘法，~40 行 numpy；输出 `flow_vectors[1536]` 替换亮度差分
- **收益**：自运动分离从硬编码补偿变为向量场投影（平移场 vs 旋转场天然可分）；碰撞/目标检测精度大幅提升
- **成本**：低（纯 numpy，50Hz 可算）

### E2. 小目标检测系统（STMD 参照）⭐ 对"钥匙/可交互物"最有价值
- **参照**：果蝇小目标运动检测神经元（STMD 能在杂乱背景中锁定 <5° 小移动目标，如同类果蝇）
- **增强**：逐小眼 `temporal - 邻域均值` 的中心-外周拮抗 + 方向过滤 → `small_target_salience[1536]`，对 Top-K 显着点跟踪位置轨迹
- **收益**：钥匙、金币、可开门等**小而动**的对象成为原生视觉显著物（注意：识别"它是钥匙"仍属教官层；果蝇层只输出"有个小目标在这"的显著图+方位）
- **成本**：中（需在 WS packet 加 Top-K 显着点字段，~16B/帧）

### E3. 尺度金字塔（Medulla 多层参照）
- **现状**：sustained 固定 5 帧窗、边缘单尺度
- **增强**：3 尺度时间窗（~80ms/200ms/500ms）+ 2 级空间下采样，输出多尺度边缘/运动能量
- **收益**：近处大物体（wall）与远处小物体分层呈现，τ 估计更稳
- **成本**：低

### E4. 颜色通道升级（R7/R8 参照）
- **现状**：color = max(green − 0.5(red+blue), 0)，cliff 依赖"下视野绿"
- **增强**：加入蓝/UV 代理通道（SM64 天空蓝 vs 地面绿的对比实际是当前 cliff 检测的本质），输出 3 通道颜色反对（绿-On/蓝-Off 等）
- **收益**：地形分类从"亮度启发"变"颜色反对"，cliff/wall 误报率下降（evaluations: cliff 误报是 neural_viz_skill 检测项之一）
- **成本**：低

### E5. 元素运动/特征轨迹（Lobula 复杂特征检测器 LC 参照）
- **增强**：对 E2 的显著目标做跨帧关联（最近邻+速度一致性），输出 `target_track {azimuth, elevation, velocity, age}`
- **收益**：可交互对象的"方位×速度×持续"特征可供行为层生成 approach 动作（教官层只需说"去那个方向"）
- **成本**：中

### E6. 视觉恒常性（对比度归一化）
- **增强**：逐扇区直方图均衡/均值归一化，消除场景整体明暗切换（进出门）造成的 drive 突变
- **收益**：减少场景切换误报（scene_change 假阳性）
- **成本**：低

## 三、优先级建议

| 阶段 | 项目 | 理由 |
|------|------|------|
| R7-a | **E1 HRC 方向流** | 修正"brightness, not flow"的根本缺陷，所有下游信号受益 |
| R7-b | **E6 恒常性 + E4 颜色反对** | 低成本降误报（cliff 误报是 neural_viz 已在追踪的 finding） |
| R8 | **E2 STMD + E5 目标轨迹** | 为"可交互物接近行为"提供原生显著图——配合教官层"去那个方向"指令 |
| R9 | E3 多尺度 | 精细化 |

## 四、协议与性能约束

- 新字段走 WS packet 帧行（`causal_schema` 已有哨兵机制，可加 `vision_schema` 同例）：`flow_vectors` 建议降采样为 16 扇区×4 方向能量（16×4=64 标量）而非全 1536 向量，带宽 +~2KB/s 可控
- 全部计算保持只读观测（不回灌模型），遵守 `test_observation_does_not_change_model` 契约
- 计算预算：HRC 逐对相关 ~1536×4 方向 numpy 向量化，微秒级；50Hz 无压力

## 五、能力边界重申

以上全部属于**果蝇自身能力群**的增强（看得更准、更快、更稳）。"看到的东西是什么"（钥匙/门/敌人）仍属训练教官层——教官层的正确用法是消费果蝇层的显著图/目标轨迹（E2/E5 输出），而非要求果蝇层输出语义标签。
