📖 这个页面在显示什么？（点开/收起说明）

一句话：这是脑模型「做过什么决策、为什么做」的时间轴回放器。它读取脑模型运行时写下的两类日志， 让你像看录像一样逐 tick 回放蘑菇体（MBON）四个动作通道的打分、多巴胺奖励信号、CX 环吸引子航向、以及教练（coach）介入事件。

数据链路与时效：脑模型 flow.json → 评估采样器（scripts/m3_mbon_eval.py，每 2 秒采一条写 runtime/mbon_eval.csv）+ skills/coach_outcomes.jsonl（教练处理记录）→ 本页。 页面每 5 秒自动拉取新数据；从脑状态变化到显示的端到端延迟 ≈ 2~7 秒。 可回放的时间窗口 = 采样器本次启动以来的全部样本（右上角显示窗口起止时间）；采样器重启会开新文件，更早的数据不在窗口内。

两种观看方式：勾选「实时跟随最新 tick」= 准实时监视器（游标始终停在最新数据）； 取消勾选 / 拖动时间轴 = 历史回放器，可任意回看窗口内任一时刻，时间戳显示该 tick 的真实采集时刻。

背景模型：脑模型是果蝇启发式三层结构 —— 感知（视网膜流+场景记忆）→ 决策（CX 中央复合体定向 + MB 蘑菇体动作价值）→ 输出（动作基元）。本页聚焦决策层与输出层：蘑菇体给四个本能动作打分， 多巴胺根据结果奖惩，最终由 CPG（本能反射）或综合决策选出动作执行。

① MBON 动作通道 · 多巴胺 时间序列

横轴 = 采样 tick（每格 ≈ 2 秒），纵轴 = 读数（-1 ~ +1）。四条彩色曲线是蘑菇体对四个本能动作的价值读数： punch拳击 / dive俯冲 / groundpound砸地 / longjump远跳。某通道 >0 表示支持该动作、<0 表示抑制。 紫色 dopamine 是多巴胺奖励信号：负值=刚完成的动作带来坏结果（权重被抑制）， 正值=好结果（被强化）。红色竖线 = 教练介入事件（对齐到最近 tick）， 标注为 异常类型/处理结论，如 fallen/unchanged = 摔倒异常且策略调整未生效。 蓝色光标 = 当前回放位置，其真实采集时刻显示在下方控制条。

② CX 16 列环吸引子（真实遥测）

果蝇中央复合体（CX）用 16 列环形神经毡编码航向。绿色环 = 真实遥测：来自 central_complex.py 的环吸引子 16 列激活（经 flow.json cx_compass 字段 → 采样器 → 本页）。 看法：白圈=当前航向列，黄点=目标列，绿色亮度=列激活强度；亮块追着黄点转 = 正在朝目标转向； 整环均匀暗淡（熵高）= 航向不确定。若该 tick 采样早于 CX 遥测上线，则回退为蓝色示意环（dopamine 相位 + MBON 能量驱动）。
